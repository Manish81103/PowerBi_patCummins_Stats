 # Pat Cummins Career Analysis (2011-2025)
 # Overview
This project is an extensive analysis of Pat Cummins cricketing career from 2011 to 2025, focusing on his allrounder performance statistics across all three formats— Test, T20, and ODI. The data has been meticulously collected from the ICC official website and analyzed using Excel and Power BI to provide visual insights into his career through interactive dashboards.

# Data Source
The data used in this project was sourced from the ICC official website, ensuring accuracy and relevance. The information has been carefully extracted and organized to maintain data integrity.

# Data Preparation
__i.Tool Used:__  Excel and Power BI

__ii.Tables:__ 6 individual tables were used, each containing detailed statistics about Pat Cummins' batting and bowling in Test, ODI, and T20I formats.

__iii.Preprocessing Steps:__

__>__ Loaded and cleaned all six datasets in Power BI

__>__ Handled missing or inconsistent values

__>__ Merged and related the tables using appropriate relationships (foreign keys like Match ID, Year, Format)

__>__ Generated calculated columns and measures for analysis (e.g., total runs, wickets, dot %, economy rate, etc.)
